# Design

Referencia visual do app, exportada do Figma.

## Conteudo

- `telas/`: PNG (390x844) do estado atual do Figma, numerados na ordem do fluxo do usuario.
- `telas/_auxiliares/`: PDFs de apoio (conteudo rolavel do login e da entrada, indicador da barra inferior).
- `telas/_fora-mvp-preferencias.png`: tela de preferencias (prioridade entre interesses, alcance geografico), fora do escopo do MVP.
- `tokens.css`: cores usadas nas telas, como variaveis CSS.
